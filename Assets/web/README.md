# Flow Web branding

The web mark adapts Flow's slanted F into a browser-window silhouette. The README header follows the original Flow Desktop Material-inspired style, using rounded shapes, tonal red surfaces, a blue music accent, and two rows of navigation and metadata badges. All SVGs are local vector artwork; the wordmark is drawn as rounded vector contours, adapted from Comfortaa Bold lettering (SIL Open Font License 1.1). Badge text has extra space for system font fallbacks.

- `logo.svg`, `logo-monochrome.svg`: standalone web marks.
- `banner-{light,dark}.svg`: repository header.
- `install-*`, `server-*`, `source-*`: large navigation pills.
- `platform-*`, `stack-*`, `license-*`: split metadata badges.

GitHub selects the variant using `prefers-color-scheme`. Original upstream marks are retained for native builds. Flow Web is an unofficial fork, not an official release.
